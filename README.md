## 使用说明

### 网页版管理（Books Web）

```bash
./start_web.sh          # 默认端口 8321
```

打开 http://127.0.0.1:8321 即可在浏览器中管理书库：
- **仪表盘**：藏书统计、分类分布、最近添加
- **书库**：关键词/分类/状态/评分/标签组合筛选，卡片式浏览
- **详情页**：编辑元数据、查看伴生 .md 笔记、浏览器内阅读/下载 PDF
- **上传**：新书上传到 swap/ 后点「重建索引」纳入书库
- **REST API**：`/api/v1/...`，自动文档见 http://127.0.0.1:8321/docs

Web 版与 CLI 共用 `.metadata/library.db`，两端修改实时互通。
代码位于 `web/`（FastAPI + Jinja2），新功能通过追加 router 扩展。

### 添加新资料

1. 根据资料类型选择对应的主题目录
2. 放入相应的子目录（books/tools/labs 等）
3. 建议在目录下添加 `README.md` 说明文件

### 目录命名规范

- **books/**: 电子书、教材
- **tools/**: 工具使用指南、配置
- **labs/**: 实验环境、靶场配置
- **reports/**: 漏洞报告、案例分析
- **ctf/**: CTF writeup、题解
- **papers/**: 论文、技术文档
- **payloads/**: POC、EXP、payload
- **samples/**: 样本文件
- **rules/**: 检测规则、Yara规则等

### 文档模板

参考资料模板位于 `.template/` 目录。
